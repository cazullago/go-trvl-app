# GoTRVL PH — Data Research Notes (2026-09-30)

Verification pass over all **37 tourist destinations** and their famous places.
Scope: pin accuracy only (centers + 5 famous places per destination, >5 km drift = correction),
fact-checking of descriptions, and hero photo sourcing.

## Output files

| File | Purpose |
|---|---|
| `assets/data/destination_corrections.json` | **122 corrections** for the parent agent to apply to `destinations_*.json`. Schema per entry: `{file, destId, field, oldValue, newValue, placeId?, source}`. Every `oldValue` was validated to match the stored data exactly (0 mismatches after review). |
| `assets/data/quest_places.json` | 371 quest entries (generated by this agent). 79 of the coordinate corrections were also applied here (the other 5 corrected places are non-quest categories: where_to_stay / where_to_buy). |
| `assets/data/RESEARCH_NOTES.md` | This file. |
| `/tmp/gotrvl_research_{A,B,C,D}.json`, `/tmp/corrections_mine.json` | Raw worker outputs (reference only). |

Correction breakdown: 91 coordinate fields (45 lat + 46 lng), 5 center fields (2 centerLat + 3 centerLng),
3 description rewrites, 5 area fixes, 18 hero photo candidates.

## Major catches

- **Dumaguete center was ~110 km off** (stored 10.3111, 123.5185 plotted near Cebu; correct 9.316, 123.30221). A systematic +1° latitude offset corrupted most Dumaguete places; 26 coordinate corrections total, including Red Rock Hot Spring, Sans Rival, Jo's Chicken Inato, Bethel Guest House, Florentina Homes, Robinsons Place.
- **Taal Volcano is a permanent danger zone since the Jan 2020 eruption — entry prohibited.** 3 descriptions rewritten (ridge views / lake boat tours only).
- **Hundred Islands**: systematic ~0.1° westward error (~10.7 km) across spots; Quezon Island + Alaminos wharf also off.
- **Oslob whale-shark watching** was a copy-paste of Kawasan Falls coords (~38 km away).
- **Sugba Lagoon** stored pin reverse-geocoded to Dapa town (~24 km wrong) → corrected to Mapcarta OSM attraction pin (9.90615, 125.90037), corroborated by whatdoyousea.com and ajourneywithmeblog (Del Carmen, boat access).
- **Sohoton Cove** stored ~26 km off → corrected to Mapcarta OSM pin (9.59708, 125.92786), corroborated by siargaohotels.ph (9.599521, 125.916516).
- **Caramoan**: 4 spots ~11.6 km south of reality. **Guisi Lighthouse** ~17 km off. **Merloquet Falls** ~36 km off. **Davao center** ~13 km off; **Pearl Farm** ~13.8 km; **Tangadan Falls** ~11 km; **Ditumabo Mother Falls** ~17 km; **People's Park in the Sky** ~7.3 km; **Monte Maria** ~8.2 km; **Baker's Hill** ~5.2 km; **Lazi Church** ~9 km; **Salagdoong Beach** pinned on the wrong coast (north → east); **Tierra Alta Lighthouse** + **Pulangbato Falls** (Dumaguete) ~9 km off each.

## Hero photos

18 `heroPhotoCandidate` entries recorded as **Wikimedia Commons file page URLs** (e.g. `https://commons.wikimedia.org/wiki/File:...`).
⚠️ **Caveat:** `upload.wikimedia.org` returns HTTP 403 to the page fetcher, so direct image URLs could not be verified as resolving. The Commons file pages are real and verified, but a live browser check is recommended before shipping the direct `upload.wikimedia.org` URLs as app hero images.

## Left unverified / judgment calls

- **Caramoan islands (Lahos, Matukad, Minalahos)** — OSM suggests stored pins are ~14 km off, but POIs couldn't be resolved; needs manual verification.
- **El Nido / Coron lagoon POIs, Donsol Manta Bowl** — geocoder too coarse; retained unconfirmed.
- **Magpupungko** — 4.99 km drift, kept per the >5 km rule (borderline).
- **Mati bestTime** — judgment call, left out.
- **Dumaguete**: Kri restaurant, Without Name (Italian Table), and the exact Dumaguete Public Market pin couldn't be reliably resolved — left as-is. Buglasan Festival (an event, not a POI) was pinned to the verified Dumaguete city center.
- **Bakhawan Eco-Park, Kadayawan** (Group D) — too vague to verify, left as-is.

## Sources used

- `map.geocode` (primary; relevance ≥ 95 preferred, full-address matches).
- Web fact-check: Mapcarta OSM attraction pins, whatdoyousea.com, ajourneywithmeblog, siargaohotels.ph, PHIVOLCS (Taal danger zone), Wikimedia Commons file pages.

## Method notes

- >5 km drift between stored coords and geocoder = correction. Every corrected value traces to a named source; nothing was invented.
- `assets/data/destinations_*.json` were **not** edited by this agent — corrections are staged in `destination_corrections.json` for the parent agent to apply.
- `quest_places.json` (371 entries: 158 where_to_go / 108 things_to_do / 105 where_to_eat) keeps the schema `{id, name, province, destination, filter, lat, lng, address, blurb, points}` — unchanged.
